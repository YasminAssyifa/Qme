Qme, aplikasi quiz simple dengan pilihan quiz yang seru.

Fitur fitur yang tersedia ada halaman utama yang berisi kumpulan quiz yang dapat dipilih, dilanjutkan pada start screen yang memperharuskan user memasukkan nama terlebih dahulu sebelum memulai quiz. Halaman quiz berisi soal dan pilihan jawaban yang dapat dipilih user dengan button dibawah yang memungkinkan user berpindah soal jika user tidak yakin dengan jawaban sebelumnya. lalu ada result screen yang menampilkan hasil yang didapat dari quiz dan tombol kembali ke halaman awal.

Aset yang dipakai adalah library icon default bawaan flutter dan stock images public.
