Qme, aplikasi quiz simple dengan pilihan quiz yang seru.

Fitur fitur yang tersedia ada halaman utama yang berisi kumpulan quiz yang dapat diisi, dilanjutkan pada start screen yang memperharuskan user memasukkan nama terlebih dahulu sebelum memulai quiz. Halaman quiz berisi pilihan jawaban yang dipilih user lalu ada result screen yang menampilkan hasil yang didapat dari quiz.

Aset yang dipakai adalah library icon default bawaan flutter dan stock images public.
